# 📊 Vendor Performance Data Analytics

## 🔍 Project Overview
This project is an end-to-end data analytics case study focused on evaluating vendor performance using real-world business scenarios.
The project demonstrates a complete analytics workflow — from data ingestion and cleaning to exploratory analysis and insight generation.

---

## 🛠️ Tech Stack
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)  
- **SQL** for querying and preprocessing  
- **Jupyter Notebook** for analysis

---

## 📈 Key Tasks Performed
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Vendor performance evaluation  
- Trend and pattern analysis  
- Insight generation and reporting  

---

## 💡 Key Insights
- Identified top-performing and underperforming vendors  
- Analyzed vendor contribution to inventory flow  
- Observed patterns in vendor efficiency  
- Provided recommendations for better vendor management
